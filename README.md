# Peptide Tracker

A single-page web app: weekly peptide schedule, syringe fill-to guides, dose logging, and calendar reminders. Fully self-contained (no build step, no dependencies).

## Run locally
Open `index.html` in any browser, or add to your phone's home screen for an app-like experience.

## Host on GitHub Pages
1. Create a repo (e.g. `peptide-tracker`) and upload these files to the root.
2. Repo **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main` / `/ (root)`.
3. Wait ~1 minute; your app is live at `https://<username>.github.io/peptide-tracker/`.

## Files
- `index.html` — the app
- `manifest.webmanifest` — PWA metadata (installable)
- `icon.svg` — app icon
